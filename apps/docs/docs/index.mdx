Casement shows the interactive UI of an MCP tool inside a Compose app. A server declares a `ui://` resource next to a tool. Casement fetches it, renders it in a locked-down web view, runs the host side of the MCP Apps bridge and reports everything it had to refuse.

```kotlin
McpAppView(
    tool = tool,
    toolInput = null,
    toolResult = result,
    client = host,
    onBlocked = { log("blocked ${it.kind}: ${it.detail}") },
)
```

One composable, four targets: Android, iOS, the web (Wasm) and the desktop. It follows spec `2026-01-26`. The current version is **{{version}}**, on Maven Central.
